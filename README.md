# Led + Botao 03/08

### Descrição da Atividade

Nesta atividade, foi desenvolvido no Tinkercad um sistema simples de controle utilizando Arduino, botão e LED. O botão funciona como dispositivo de entrada, enviando uma informação ao Arduino, que processa o comando e controla o acionamento do LED como saída. A prática permite compreender a integração entre circuito e programação em projetos de IoT.
